This project focuses on developing an IoT-based smart door lock
system that combines RFID technology with the Blynk mobile
application to enhance security and convenience. The system uses a
NodeMCU (ESP8266) microcontroller connected to an RC522 RFID
reader to identify authorized users through their RFID cards or tags.
When a valid card is scanned, the system unlocks the door using a
servo motor or relay mechanism, and the status of the lock is
instantly updated on the Blynk app. The app also allows users to
remotely monitor and control the door from anywhere via the
internet. Unauthorized access attempts are denied and can trigger
notifications for added safety. By integrating IoT connectivity with
RFID-based authentication, this project offers a secure, low-cost,
and user-friendly solution for modern smart homes and offices..

Applications

 Educational institutions.
 Residential apartments and housing societies.
 Hospitals and laboratories.
 Industrial and factory primises.

 Libraries and research center.

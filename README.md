# Door Unlocking System Using RFID

## About the Project
This project introduces an IoT-based Smart Door Lock System that integrates RFID technology with NodeMCU to provide secure, automated, and convenient door access.

## Hardware Used
- NodeMCU ESP8266
- RFID Module
- RFID Card/Tag
- Servo Motor
- Buzzer
- Jumper Wires

## Software Used
- Arduino IDE
- Embedded C/C++

## Working
1. The RFID card is scanned using the RFID module.
2. NodeMCU reads the RFID card information.
3. The card ID is checked with the authorized ID.
4. If the card is valid, the door is unlocked.
5. If the card is invalid, access is denied.

## Features
- RFID-based authentication
- Secure door access
- Automatic door unlocking
- IoT-based system

## Applications
- Homes
- Offices
- Laboratories
- Smart buildings
